# Geodle

A daily Wordle-style guessing game built into Geometry Dash.

Press **F8** anywhere (main menu or in a level) to open Geodle.

- One Geometry Dash word per day, the same for every player (UTC day)
- 6 guesses, Wordle colour rules (duplicate letters handled correctly)
- Statistics, streaks, guess distribution and game history
- 13 unlockable achievements with animated notifications
- Physical keyboard + on-screen keyboard, Esc / F8 to close
